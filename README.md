# card-duel

卡牌對戰的可玩原型：單一 `index.html`、原生 JS，手機直式可玩，桌機會自動改成左右兩欄。

## 玩法
用手機打開 GitHub Pages：`https://dan0618x.github.io/card-duel/`

主頁有四種模式：
- 🗺️ **冒險**：3 張隨機地圖、每張 10 步，最後打王；每過一張地圖招募一位夥伴
- 🔮 **守護**：守住水晶撐過 9 波敵人；排隊中的敵人每回合攻擊水晶
- 👑 **王者連戰**：一開始組好 3 人隊伍，連打三隻王
- 🎯 **練習**：自選主角、輔助和對手，打一場

主頁上的其他功能：
- 牌組設定：每個角色都有戰鬥牌組和輔助牌組
- 遊戲設定：敵人 AI 難度、攻擊對攻擊的規則、怪物意圖預告、速度、震動
- 冒險、守護、王者連戰會自動存檔，關掉網頁之後可以從主頁繼續

## 調數字
所有卡牌、角色、怪物、地圖生成、各模式、裝備、AI 參數都在 `index.html` 最上面的 `CONFIG` 物件，改完重新整理即可。

## 部署
GitHub Pages 設定成從 `main` 分支的根目錄發布。合併進 `main` 後一兩分鐘網站就會更新。
